### Sobre mí

Soy **Álvaro** ([@Zak208](https://github.com/Zak208))<br/>
Desarrollador de software enfocado en crear herramientas bien construidas, eficientes y cuidadas visualmente.

<br/>

**Web & Interfaces**<br/>
Diseño de sitios y aplicaciones con maquetación limpia, micro-animaciones fluidas y experiencia de usuario cuidada.

<br/>

**Backend & APIs**<br/>
Desarrollo de servicios y automatizaciones con Node.js y Python, integrando bases de datos relacionales (PostgreSQL, MySQL, SQLite).

<br/>

**Escritorio & Hardware**<br/>
Software nativo para Windows con procesamiento de audio en tiempo real (FFmpeg, Whisper AI) y comunicación directa con periféricos USB.
